### ☁️ Featured Cloud Projects

**[AWS Secure Cloud Infrastructure Automation](https://github.com/powerup33/AWS-secure-cloud-infrastructure-automation)**
*Tools: AWS, Terraform, Python/Boto3, GitHub Actions, Checkov*

Secure AWS environment built entirely with Terraform:

- Multi-region **CloudTrail** audit logging with log file validation, delivered to an encrypted, TLS-only S3 bucket
- Custom **VPC** with public and private subnets and a locked-down default security group
- **EC2 access through Systems Manager Session Manager**: no SSH keys, no inbound ports, IMDSv2 required
- **Least-privilege IAM** and hardened S3 storage (Block Public Access, encryption, versioning)
- **Python/Boto3 scripts** that audit IAM users for stale access keys and missing MFA
- **CI/CD pipeline** running Terraform validation and Checkov security scans on every push, with documented design trade-offs
